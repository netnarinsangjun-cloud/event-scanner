# Event Scanner

หน้าสแกน QR แบบต่อเนื่องสำหรับเจ้าหน้าที่ลงทะเบียน งาน Unlocking New Growth (สภาหอการค้าแห่งประเทศไทย 10 ก.ย. 2569)

เปิดหน้า `scanner.html` บนมือถือหรือโน้ตบุ๊ก ใส่รหัสเจ้าหน้าที่ครั้งเดียว แล้วเล็งกล้องที่ QR ของผู้เข้างานได้ต่อเนื่อง
ระบบเช็คอินอยู่บน Google Apps Script หน้านี้เป็นแค่ตัวสแกนที่คุยกับระบบผ่าน API
